# Chromatica Color Studio

**Open it:** https://chromatica.juliojimenez.com

Type an idea, get four palette directions with exact print and screen codes, PMS and
historical pigment matches, guaranteed contrast, a written brief, an AI image prompt and a
mood board of real photos ranked by how closely their colors match the palette.

Install it: Chrome shows an **Install app** button in the top bar. Safari: File › Add to
Dock. iPhone: Share › Add to Home Screen.

This repo holds only the finished app. Source, engine and notes live in a private repo.
